# Shrutartha Rakshit — Personal Casebook

A responsive detective-editorial personal website built with plain HTML and CSS. No build tools or dependencies are required.

## Preview
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `the-science-of-observation`.
2. Upload `index.html` and the `images` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment and open the URL GitHub Pages provides.

## Add your photographs (site owner only)
The public website has no upload controls or instructions for visitors. To add your own photographs, create an `images` folder beside `index.html` and use these filenames, or change the `src` paths in the HTML:

- `images/portrait.jpg`
- `images/portrait-candid.jpg`
- `images/workspace.jpg`
- `images/detail.jpg`

The image areas display designed file labels until you add the corresponding files. Keep the images in the repository so every visitor can see them.

## About the case note
The relationship case is written as a first-person account, distinguishing the concealed/deleted chats and later acknowledged concealment from interpretations about motive or the exact meaning of later social-media activity. Edit the wording if you want it to reflect a more exact, personally verified timeline.

The site uses original text and a detective-editorial aesthetic inspired by classic casebooks and BBC's *Sherlock*. It is not an official show website.

## Fictional case archive
The casebook includes three clearly labelled fictional cases submitted to Shrutartha by a friend and narrated in first person: a changing alibi, an unverified Instagram identity, and an exaggerated public persona. Each file focuses on evidence and proportionate verification rather than doxxing, public humiliation, or claims about unverified motives.
